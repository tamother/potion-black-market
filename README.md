# 魔药黑市 · Potion Black Market

手机横屏优先的单人像素经营游戏。操控店主在月隐巷的小店和镇区走动，接待每天的来客，采购、定价、查看布告与仓库，白天准备，入夜开业并播放客人购物与金币收款，最后打烊结算。没有固定通关日；破产或永久查封结束本轮。

## 操作与店内物件

电脑用 WASD / 方向键移动，E / 空格交互。手机在左侧 HUD 下方的大面积空白区域任点起手，摇杆以触点为圆心，拖出圆盘仍持续移动，抬手停下，右侧按钮交互；也可以点击物件，让人物自动走近再打开。桌椅、墙壁有碰撞。物件窗口暂停移动，小夜的资讯气泡允许继续走动，不消耗经营时间。推荐横屏，竖屏提示可关闭。底部首次指引按触屏/键盘适配，实际移动后提示交互，成功操作后自动收起；刷新和换场景保留完成状态，不再常驻。

| 物件 | 功能 |
| --- | --- |
| 每日来客 | 对话、查看委托、交付或拒绝 |
| 猫头鹰小夜 | 每天自动浮现店内消息，自动翻页并收起，设置中可重读 |
| 布告栏 | 传闻、跨日约定、调查、往事四个标签 |
| 荣誉榜 | 大厅侧边独立陈列架上的三枚纹章，查看三势力声望、合作阶段与权益 |
| 店门 | 免费前往月隐镇；集市、公会、旧巷都有可走近交谈的联系人 |
| 仓库箱 | 点药水查看实际批次、成本与保质期 |
| 中央主柜台 · 进货簿 | 查看商队供应并采购，来客在柜台前等候 |
| 魔药货架 | 调整零售价、查看参考行情 |
| 基础账本 | 每日收入/实际支出、余额、债务和还款 |
| 营业牌 | 入夜开业，播放购物与收款，也可直接查看收据 |
| 黑市商人 | 定期到访，出售水晶球 |
| 水晶球 | 购入后水晶球自然嵌入左下箱盖的背景画面，点击占卜，付费降低当晚店内意外概率 |

访客会进店带来当日委托，普通订单的品种、数量和报价会随经营进度变化。缺货可以先去备货再回谈，未处理的委托入夜开业后失效。

主柜台位于大厅中央，地毯随柜台缩小，来客从入口走到柜台前，夜市购物也沿同一路线。基础账本与财务人员在右侧，荣誉陈列架在大厅另一侧，保留左右通道。

物件窗口缩小并避开手机四边安全区域；按钮采用早期像素版的木金/紫色配色，文字去除重影。所有交互窗口采用固定的标题、标签、内容区和底部操作。商品按标签切换；长篇资讯、纪事、流水和批次用左右翻页，无需上下滚动。财务日期也用左右切换。

## 每日行动与夜市

行动点每天恢复，不累计。采购、改价、履约、雇佣和护店等经营操作需要预留行动点。走路、查看、拒绝委托、处理债务和开业不消耗行动点。

黑市白天备货、晚上开业。购物与收款回放对应实际零售，可以加速或直接查看收据。游戏先结算并保存，再播放回放，刷新后可以恢复收据。次日可以找埃德温解读已结算的收支和销量。

## 城镇、跨日约定与荣誉榜

从店门或右上“镇”字前往月隐镇：集市认识米拉，公会认识塞拉，旧巷认识阿缇。走路、往返、查阅、结识与谢绝都免费；每个渠道当天有有限总货量，反复进出不刷新。

推进经营后会收到跨日邀约。接受委托后默认留货，不参加夜间零售，也可以在留货管理中重新开放零售。须回到联系人处交货。取消或逾期可能影响关系。

声望和合作权益可在大厅的荣誉陈列架查看。完成关键委托可以推进合作，重复普通小单的声望收益会逐渐递减。

- 公会提供预订，需要预付并预留仓位。
- 王国提供独立的合法库存，合作后可减免部分许可费。
- 黑市提供替代货源，也可以打听即将到来的行情。经营管制品仍有风险。

集市轮换供应折价散货，保质期以游戏内显示为准。布告和联系人会提供供需线索。

## 财务人员

打烊报告提供基础收支、售出数量和纪事。可通过基础账本雇佣埃德温，入职后按日支付薪资。次日可以到柜台旁请他解读已结算的账目。

旧存档不会自动获得财务人员；缺失的旧历史客流/售价不追溯编造。日薪固定自动结算，没有通用员工、排班或升级系统。

## 意外与水晶球

每日来信可能预警窃贼、货架破损、魔灯熄灭或符文修缮。结果在结算时确定，可能影响现金、库存、需求或维修支出。

可向黑市商人购买水晶球，付费占卜以降低当晚店内意外的风险。购入、使用及预兆都会即时保存。

基础账本的“今日预算”提前列出固定费用和库存费用上限，额外留出应急金。囤货会占资金并增加护养成本；只重复做同一种补给单可能覆盖不了长期费用。

## 本地运行

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm test
npm run simulate
npm run build
npm run preview
```

默认开发地址 http://localhost:5173。浏览器无需账号。生产 dist 可发布到 HTTPS 静态主机根目录。

首次端到端测试先执行 `npx playwright install chromium`，再 `npm run test:e2e`。已有系统 Chromium 时：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

## 经营规则与存档

经营需要承担租金、保养、销售耗材和许可费用，并管理会计薪资、债务利息与药水保质期。库存按先进先出销售。管制随商品和市况变化，游戏内会提供执法预警。未付费用会计入欠款。

经济操作即时写入 `potion-black-market-v1`，格式2，支持原格式1迁移与旧格式2缺省财务、来信及水晶球/预兆字段。兼容缺失的每日行动和城镇字段；旧声望保留，不凭空补出关键合作经历。完整保存随机状态、库存、延迟后果、报告阶段。普通跨标签页冲突会阻止旧页写入；localStorage不支持跨窗口原子事务，建议单标签经营。

经济存档保存当前店铺/城镇位置；人物坐标分别存在 `potion-black-market-room-v1` 与 `potion-black-market-town-position-v1`，绑定本轮种子；损坏、其他种子或落在障碍物内时安全回到店内起点。走路不会消耗经济随机数。声音设置独立保存。清除数据、换设备或无痕结束不会同步。

## 项目结构与美术

- `src/engine/`：独立的种子经济引擎、事件、FIFO、持久化与财务雇佣。
- `src/world/`：房间几何、碰撞/寻路、键盘与触控、角色/NPC、场景样式。
- `src/ui/`：固定窗口、标签/翻页、图标仓库、商品买卖、来信、账目与系统窗口。
- `src/components/ShopPanels.tsx`：物件与窗口映射。
- `src/App.tsx`：游戏状态、CAS保存、弹窗与场景组合。
- `public/world/`：精细像素房间、主角四方向四帧图集、四类NPC前后图集、猫头鹰图集；文字/HUD/碰撞均为真实代码。
- `tests/`：逻辑与浏览器回归测试。

中文像素字体为本地 Fusion Pixel（OFL-1.1），许可证在 public/fonts/。没有第三方运行时服务、跟踪、付款或服务器反作弊。

# 魔药黑市 · Potion Black Market

手机横屏优先的单人像素经营游戏。操控店主在月隐巷的小店和镇区走动，接待每天的来客，采购、定价、查看布告与仓库，白天准备，入夜开业并播放客人购物与金币收款，最后打烊结算。没有固定通关日；破产或永久查封结束本轮。

在线试玩：https://potion-black-market-tamother.sugarydill257.chatgpt.site

## 操作与店内物件

电脑用 WASD / 方向键移动，E / 空格交互。手机在左侧44%宽、HUD下方的大面积空白区域任点起手，摇杆以触点为圆心，拖出圆盘仍持续移动，抬手停下，右侧按钮交互；也可以点击物件，让人物自动走近再打开。桌椅、墙壁有碰撞。物件窗口暂停移动，小夜的资讯气泡允许继续走动，不消耗经营时间。推荐横屏，竖屏提示可关闭。底部首次指引按触屏/键盘适配，实际移动后提示交互，成功操作后自动收起；刷新和换场景保留完成状态，不再常驻。

每天有一位访客进店等候，可以携带当日多份委托。前3天保留原入门报价，第4天起普通订单的品种、数量和报价比例会变化；不展示替玩家算好的毛利、机会差额或剧情结果。缺货可以先去备货再回谈；已交付不能重复领奖，未处理的委托入夜开业后失效。

主柜台位于大厅中央，地毯随柜台缩小，来客从入口走到柜台前，夜市购物也沿同一路线。基础账本与财务人员在右侧，荣誉陈列架在大厅另一侧，保留左右通道。

物件窗口缩小并避开手机四边安全区域；按钮采用早期像素版的木金/紫色配色，文字去除重影。所有交互窗口采用固定的标题、标签、内容区和底部操作。商品按标签切换；长篇资讯、纪事、流水和批次用左右翻页，无需上下滚动。财务日期也用左右切换。

## 每日行动与夜市

每天恢复 **8行动点**，不累计、不付费补充：每笔采购1点、每次实际改价1点、履约2点；雇佣/购入水晶球/护店各1点。城镇每次接受跨日委托1点、交付2点，情报1点。原每日最多2份即时特殊履约上限保留。走路、查看、拒绝、还款/补欠款/融资和开业免费；无效操作、未改变的价格不扣点。8点可完成4类药水各一次补货和改价，订单与护店需要提前预留。旧档只按可确认的特殊履约初始化，不追扣无法还原的旧采购。

黑市白天备货、晚上开业。营业牌显示“已经备好货，准备开业”；入夜后每位真实购买者买1–3瓶，数量与金额严格对应最终实际零售，不制造假成交。委托报酬已提前到账，回放不会重复计入。默认2倍，可切4倍或直接查看简单收据；费用和损失在收据归账。先结算并保存再播放，刷新恢复收据，不重复结算；保存失败则尚不开业，保留原状态供重试；结局可查最后一晚收据。减少动态效果偏好直接显示收据。次日找埃德温解读利润/现金/费用/销量，已去掉计算过程标签。

## 城镇、跨日约定与荣誉榜

从店门或右上“镇”字前往月隐镇：集市认识米拉，公会认识塞拉，旧巷认识阿缇。走路、往返、查阅、结识与谢绝都免费；每个渠道当天有有限总货量，反复进出不刷新。

第3天起出现跨日邀约；关键合作最早在第3、10、18天推进下一段。最多同时接2份、每势力1份。接受1行动，交付2行动；接下后默认留货，不参加夜间零售。委托分需求、来信、留货管理三页，可随时免费改为开放零售。留货仍可能损失或过期，不是保险。必须回到联系人处交货；报酬只到账一次。未接可免费谢绝，已接取消关系−4，打烊仍未完成的到期约定关系−8，无额外现金罚款。

声望在大厅内的荣誉陈列架查看：认识联系人后，20声望为“熟识”；50声望加1份关键委托为“合作”；80声望加3份为“信任”。重复普通小单的声望收益逐渐递减，旧档高声望不会跳过关键合作。

- 公会：次日预订，按当日进价94%/92%/90%，每日4/4/6瓶；提前付款、占仓库容量，到货前不能卖。
- 王国：独立合法库存，按进价97%/94%/92%取整，每日3/3/4瓶；合作后周许可费降至24 G，违法调查照常。
- 黑市：118%/110%/104%进价的替代货源，每日3/3/4瓶；管制品仍增加风险。合作后可付5 G、1行动确认即将到来的行情，同一条消息不重复收费。

集市每天还从三类合法药中轮换一种折价散货，总共4瓶、九折进价；治疗药水最多已存放2天，以页面剩余保质期为准。布告和联系人会给出未来几天的供需线索，可靠情报才说明具体日期与幅度。它们影响真实供需，不能保证一定获利。

## 财务人员

打烊报告始终只提供基础收支、售出数量和纪事。到基础账本的“财务人员”标签支付 **120 G** 让埃德温入职，之后**每天日薪10 G**，入职当天也计薪。次日去账桌旁找他，才能解读已经结算的日期；报告不解锁分析标签。补救期、结算中或已结束时不能雇佣，重复雇佣不重复扣费。

旧存档不会自动获得财务人员；缺失的旧历史客流/售价不追溯编造。日薪固定自动结算，没有通用员工、排班或升级系统。

## 意外与水晶球

每日来信预警暗巷窃贼、货架破损、魔灯熄灭或符文修缮，发生概率为14% / 28% / 44%，结算时才抽取结果。分别影响闲置现金、真实库存、零售需求或维修支出。前两天没有店内意外，意外发生后下一天暂时平静。

经营满5天后，第6天黑市商人上门。水晶球售价**160 G**，购入后每次护店占卜**8 G**，仅当晚将店内意外概率相对降低60%（例如44%→17.6%），每日最多一次。它不能保证平安，不影响王国调查或市场事件。商人每隔3天再来；平静之夜不会收取占卜费。购入/使用和预兆均即时保存，刷新不会重抽。

基础账本的“今日预算”提前列出固定费用和库存费用上限，额外留出应急金。囤货会占资金并增加护养成本；只重复做同一种补给单可能覆盖不了长期费用。

## 本地运行

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm test
npm run simulate
npm run build
npm run preview
```

默认开发地址 http://localhost:5173。浏览器无需账号。生产 dist 可发布到 HTTPS 静态主机根目录。

首次端到端测试先执行 `npx playwright install chromium`，再 `npm run test:e2e`。已有系统 Chromium 时：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

## 经营规则与存档

初始现金500 G、债务300 G、仓库30格。每日租金12 G、保养4 G；售出/交付每瓶耗材2 G，打烊后留存每瓶护养1 G，每7日许可费30 G（王国合作后24 G）；埃德温入职后另有10 G日薪。五种药水按FIFO销售，新鲜治疗药水购入当日起第7天末过期；集市折价治疗药水最多已存放2天，预订货到货当日开始保质期。每七天债务计息5%，向上取整加入债务。隐身一直违禁，狂暴战时管制。原战争/瘟疫/走私因果链、六类市场事件、三阵营和执法预警保留。未付经营费用合并为欠款，沿用两个后续营业日的补救期限。

经济操作即时写入 `potion-black-market-v1`，格式2，支持原格式1迁移与旧格式2缺省财务、来信及水晶球/预兆字段。兼容缺失的每日行动和城镇字段；旧声望保留，不凭空补出关键合作经历。完整保存随机状态、库存、延迟后果、报告阶段。普通跨标签页冲突会阻止旧页写入；localStorage不支持跨窗口原子事务，建议单标签经营。

经济存档保存当前店铺/城镇位置；人物坐标分别存在 `potion-black-market-room-v1` 与 `potion-black-market-town-position-v1`，绑定本轮种子；损坏、其他种子或落在障碍物内时安全回到店内起点。走路不会消耗经济随机数。声音设置独立保存。清除数据、换设备或无痕结束不会同步。

## 项目结构与美术

- `src/engine/`：独立的种子经济引擎、事件、FIFO、持久化与财务雇佣。
- `src/world/`：房间几何、碰撞/寻路、键盘与触控、角色/NPC、场景样式。
- `src/ui/`：固定窗口、标签/翻页、图标仓库、商品买卖、来信、账目与系统窗口。
- `src/components/ShopPanels.tsx`：物件与窗口映射。
- `src/App.tsx`：游戏状态、CAS保存、弹窗与场景组合。
- `public/world/`：精细像素房间、主角四方向四帧图集、四类NPC前后图集、猫头鹰图集；文字/HUD/碰撞均为真实代码。
- `tests/`：逻辑与浏览器回归；`scripts/simulate.ts`：三策略各300局、最多100天。
- `docs/simulation-results.json` / `simulation-runs.csv`：三策略900局汇总与原始结果。
- `scripts/balance-risk.ts` / `docs/risk-balance-results.json`：另900局分散经营、选择占卜、重复补给对照。
- `scripts/balance-town.ts` / `docs/town-balance-results.json`：四路线各120局，检查跨日委托、预订与资产守恒。

中文像素字体为本地 Fusion Pixel（OFL-1.1），许可证在 public/fonts/。没有第三方运行时服务、跟踪、付款或服务器反作弊。

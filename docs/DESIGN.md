# 实现决策
严格遵循 REQUEST.md，不增加生产、战斗、账号或员工。

- 移动优先：经营/仓库/事件/账本；桌面左导航和右侧订单栏，移动底部导航。
- 色彩：#181512 背景、#211d18 面板、#e9ddc8 文本、#daa454 按钮、#9382ce 魔法点缀。6px 圆角，暖灰细分隔线。正文使用系统中文无衬线，标题使用衬线。
- 游戏美术为生成的像素店铺横幅；按钮、金额、信息、图表均真实 DOM/SVG。
- 状态更新为纯函数，UI 只派发命令。PRNG 完整存档。
- 每次成功命令立即保存；结算带 expectedDay 和 report 阶段双重保护。跨标签页冲突检测，旧标签需刷新。
- 采购批次成本估值净资产；营业利润扣销货成本、过期损失、12G费用、罚款；利息单独作为融资费用。现金流包含实际采购、偿债、借款。
- 利息在第 7、14、21…天结束资本化；不扣现金。未付固定成本进入逾期，最迟在违约日后第二天结算前补救。
- 治疗药水购入日算第 1 个持有日；第 7 日先卖后过期。
- 王国订单和战争军需订单 +8 王国；公会订单 +8 公会；医生援助 +12 公会；走私 +12 黑市、+20 风险、-5 王国；普通违禁销售每件+8风险；没有非法交易每日-5。
- 风险 50–74 调查概率 5%–15%，75–100 为15%–30%；首次调查只警告/罚款/没收，再次发生于明确警告后、风险>=90且当天违法、已有处罚记录才永久查封。
- 三链有冷却、前置状态、唯一延迟效果ID。战争与瘟疫不同时启动；走私可伴随。独立事件有持续时间/冷却/数值影响。
- 军方/黑市/医生订单拒绝后选择正常经营或拒绝援助，无重复奖励；两次特殊行动上限。公会声望20可解锁一次100G借款，属于新增债务。
- 本地存档不能防玩家手动修改浏览器存储；输入校验保护损坏状态，无服务器反作弊。

## 全界面像素风改版（2026-10-23）

按试玩反馈统一改为复古像素 RPG 界面：暗紫石墙、暖木招牌、钉角木框、凹槽输入、紫色按钮、羊皮纸订单/事件/账本和阶梯图表。经营、仓库、事件、账本、规则、重开、破产及营业报告使用同一套风格。

- 字体：Fusion Pixel 12px 简体中文比例字体，OFL-1.1，可商用；本地托管并预加载，不依赖第三方字体 CDN；授权与上游声明位于 public/fonts/。
- 图标：PixelIcons.tsx 提供整数网格填色图标，替换原细线圆弧图标。药瓶是 crispEdges 像素几何，界面仍使用可访问的原生按钮和输入框。
- 样式：styles.css 负责原有布局约束，pixel-theme.css 集中像素皮肤与对应尺寸适配；320–1440px 下保持实际采购、售价、订单操作。
- 仓库新增按五种商品组织的视觉货柜，只呈现真实库存、批次数和剩余容量，不增加仓位或生产系统。
- 原有游戏引擎和存档版本保持兼容。长结算报告初始焦点改为报告顶部，避免原生 dialog 自动滚动到下方按钮。

## 横屏可操控店铺更新（2026-10-24）

最新交互和财务功能以 `superpowers/specs/2026-10-23-walkable-shop-design.md` 为准。App切换为店铺场景组合，原四页改由物件交互打开；运动、碰撞和小网格寻路在src/world中，不消耗经济RNG。角色位置使用独立绑定种子的存档，不触发经济CAS版本。

用户后续明确授权财务人员这一单独雇佣例外：120G一次费用、持久入职，book.staffCost与可选ledger.staffCost核算，accountantHiredDay控制分析UI。旧档补默认字段；原雇员系统范围禁止不再适用于这一明确例外，但不拓展通用员工系统。
